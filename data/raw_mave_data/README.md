# raw_mave_data

Hand-populated starting point for the Dockerized variant-annotation pipeline
(`scripts/variant_annotation_pipeline.sh`, driven by
`scripts/run_variant_annotation_pipeline.sh` -- see
`docs/variant_annotation_pipeline.md`). This is the one directory in the
pipeline's data flow that isn't auto-generated — everything downstream is
produced by running the pipeline.

## Data flow

```
data/raw_mave_data/                       (this directory -- you populate it)
        |  scripts/run_variant_annotation_pipeline.sh copies it in
        v
data/intermediate/variant_annotation/data/ (gitignored; mounted as the
                                             variant-annotation pipeline's
                                             VARIANT_DATA_DIR for the run)
        |  variant_annotation_pipeline.sh runs Steps 1-18 + condensed/expanded
        |  frame assembly
        v
data/mave_data/                            (final gzipped outputs, tracked)
```

## Expected contents

Files sit directly in this directory (no `cvfg/` or version subdirectories).
Only the files `scripts/variant_annotation_pipeline.sh` actually reads as
*input* need to be here — the `cvfg_variants.1.tsv` .. `.17.tsv` intermediates
and the final `integrated_variant_effect_dataset*.tsv` files are generated by
the run itself and should not be pre-populated.

```
cvfg_variants.0.tsv                              # REQUIRED -- Step 1 input:
                                                  #   harmonized variant list across
                                                  #   the 83 MAVE datasets
Supplementary_Data_3.xlsx                        # REQUIRED -- Step 14 assay metadata
                                                  #   (Curation worksheet)
score_sets.tsv                                    # REQUIRED -- Steps 11, 13, 14
                                                  #   (dataset name / score-set mapping)
data_frame_missense_variants_MP2_properties.csv.gz # REQUIRED -- Step 12 (MutPred2 scores)
extended_ensembl_consequence.csv.gz               # REQUIRED -- simplified-consequence step
```

## Not here on purpose

Large, static, non-CVFG-specific reference data (AlphaMissense, REVEL,
SpliceAI VCFs, the MANE summary, ClinVar/ClinGen/gnomAD caches) stay wherever
your variant-annotation checkout already has them -- see
`docs/variant_annotation_pipeline.md`. They're read via variant-annotation's
own repo bind mount and are unaffected by the `VARIANT_DATA_DIR` override this
project uses.
