# OddsPath Calculations 

This Jupyter notebook calculates **OddsPath** (likelihood ratios) for MAVE datasets to enable clinical calibration of functional assay results according to ACMG/AMP variant classification guidelines.

## Overview

OddsPath quantifies how well a functional assay discriminates between pathogenic and benign variants using ClinVar-annotated control variants. The calculated likelihood ratios (LR+ and LR−) can be translated into ACMG/AMP evidence codes (PS3/BS3) at varying strength levels.

The pipeline:
1. Loads the integrated variant effect dataset
2. Standardizes functional classifications across datasets
3. Identifies and flags splice variants
4. Calculates OddsPath (likelihood ratios) per dataset using ClinVar controls
5. Maps likelihood ratios to ACMG/AMP evidence strength levels

## Methods

### Functional Classification Standardization

Author-reported functional classifications are mapped to three standard categories:

| Standard Class | Description |
|----------------|-------------|
| **Normal** | Functionally normal/wild-type behavior |
| **Abnormal** | Loss-of-function or damaging |
| **Indeterminate** | Uncertain functional effect |

Classifications labeled "Not specified" are excluded from OddsPath calculations.

### Splice Variant Handling

Variants are flagged as splice-affecting if:
- Any SpliceAI delta score ≥ 0.2 (`DS_AG`, `DS_AL`, `DS_DG`, `DS_DL`)
- VEP consequence is `splice_site_variant`

For amino acid-level assays, splice variants are propagated across all codon changes at the same position and excluded from calibration (see methods)

### OddsPath Calculation

Likelihood ratios are calculated as:

```
LR+ (OddsAbnormal) = P(Abnormal|Pathogenic) / P(Abnormal|Benign)
                   = (path_abnormal / pathogenic_controls) / (benign_abnormal / benign_controls)

LR− (OddsNormal)   = P(Normal|Pathogenic) / P(Normal|Benign)
                   = (path_normal / pathogenic_controls) / (benign_normal / benign_controls)
```

**Pseudocount adjustments:**
- If no benign variants are functionally abnormal: +1 pseudocount added
- If no pathogenic variants are functionally normal: +1 pseudocount added

### Evidence Strength Mapping

OddsPath values are mapped to ACMG/AMP evidence codes:

| OddsPath Range | Evidence Code |
|----------------|---------------|
| < 0.053 | BS3_strong |
| 0.053 – 0.23 | BS3_moderate |
| 0.23 – 0.48 | BS3_supporting |
| 0.48 – 2.1 | Indeterminate |
| 2.1 – 4.3 | PS3_supporting |
| 4.3 – 18.7 | PS3_moderate |
| 18.7 – 350 | PS3_strong |
| > 350 | PS3_very_strong |

## Notes

- Datasets must have either author-reported functional classifications or defined score intervals to be included
- The MSH2_Scott_2022 calibration uses clinically-validated thresholds from Scott et al. 2022 (PMID: 36550560)
- Variants with mapping flags (`Flag = '*'`) are excluded
- Variants with conflicting ClinVar classifications on the nucleotide level for protein assays are excluded from control sets
